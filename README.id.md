# Before the Bite

Panduan interaktif pencegahan rabies. Satu halaman tanpa langkah build.

[English](README.md)

## Isi

- Pemilih peran ("Pilih peranmu") yang membuka panduan.
- Alur pencegahan dalam tiga tahap: sebelum terpapar, saat berinteraksi dengan hewan, dan setelah terpapar.
- Timer cuci luka.
- Cek mitos dan fakta dengan validasi jawaban.
- Langkah komitmen yang harus diselesaikan sebelum alur berlanjut, dan navigasi bertahap.

Teks panduan berbahasa Indonesia.

## Menjalankan

Buka `index.html` di peramban, atau sajikan foldernya:

```bash
python3 -m http.server 8000
```
