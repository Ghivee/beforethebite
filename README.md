# Before the Bite

An interactive guide to preventing rabies. It is a single page with no build step.

[Bahasa Indonesia](README.id.md)

## What it has

- A role picker ("Pilih peranmu") that opens the guide.
- A prevention flow in three stages: before exposure, while interacting with an animal, and after exposure.
- A wound-washing timer.
- A myth and fact check with answer validation.
- A commitment step that has to be completed before the flow moves on, and a stepped navigation bar.

The text is in Indonesian.

## Running it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
